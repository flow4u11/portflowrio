# Tool and technology brand assets

These local assets identify the tools mentioned in the portfolio. No marks were
invented, redrawn, or generated. They do not imply endorsement or a partnership.
The adjacent text identifies each product, and the mark itself is decorative.

`attribution.json` records every file's source URL, provider, version, SHA-256,
known license, and brand-guideline URL. Retrieved 2026-10-07.

- **Simple Icons 16.34.0:** Original monochrome SVG files from
  [the published upstream release](https://github.com/simple-icons/simple-icons/tree/16.34.0/icons).
  Displayed at their original proportions in the surrounding text color.
  The package is CC0-1.0; individual brand rights and recorded icon licenses still
  apply. See the retained `simple-icons-LICENSE.md` and
  `simple-icons-DISCLAIMER.md`, plus the per-icon source/guideline links.
- **Git:** Git logo by Jason Long, licensed under
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), sourced from
  [Git's official logos](https://git-scm.com/downloads/logos).
  The monochrome adaptation is supplied by Simple Icons.
- **JavaScript and Zod:** MIT logo licenses recorded by Simple Icons. Original
  source links and licensing notices are included with the assets.
- **Premiere Pro, After Effects, Substance 3D Painter:** Intact product icons
  from Adobe's public website asset host, linked by each official product page.
  Original colors are retained. Brand marks belong to Adobe.
- **VS Code:** Intact blue `vscode.svg` from Microsoft's official
  [downloadable icon archive](https://code.visualstudio.com/brand).
  The archive's README is retained as `vscode-README.txt`.
- **Playwright:** Intact colored SVG from [the official site](https://playwright.dev).
- **Motion, CapCut, Fastwork:** Intact favicons linked by the respective official
  product websites. No substitute or hand-drawn marks are used.
- **Codex and ChatGPT:** Original bundled icons from the installed official
  `com.openai.codex` desktop app, version `26.930.61225` (build `13232`).
  ICNS frames were converted to 64px PNGs without changing the artwork or
  proportions. These brand assets belong to OpenAI; see the
  [OpenAI brand guidelines](https://openai.com/brand/).
- **Supabase Auth:** Uses Supabase's actual parent brand mark, recorded as an
  alias. No separate Auth symbol is fabricated.
- **ExcelJS:** No independent official logo was found in its
  [official repository](https://github.com/exceljs/exceljs). Its generated GitHub
  organization identicon is not used as an app logo; the tool stays text-only.

Brand/trademark assets do not acquire an open-source license merely because
they appear in this folder. Check the recorded source guidelines when changing
their use. The component deliberately returns no mark for unknown products.
